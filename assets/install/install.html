iPhoneでの開き方

  1. カメラでQRコードを読み込みます。
  2. Safariで開きます。
  3. 共有ボタンから「ホーム画面に追加」を選びます。
  4. 追加すると、次回からホーム画面のアイコンで開けます。

Androidタブレットでの開き方

  1. カメラまたはQR読み取り機能でQRコードを読み込みます。
  2. Chromeで開きます。
  3. メニューから「ホーム画面に追加」または「アプリをインストール」を選びます。
  4. 追加すると、次回からホーム画面のアイコンで開けます。
